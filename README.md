# Monitoramento · v0.6.10

Monitoramento de pragas no campo pelo celular, com GPS. App de arquivo único (PWA), com Leaflet 1.9.4 embutido (licença BSD-2, em `LICENSE-leaflet.txt`).

- Abre no modo de demonstração, com dados inventados (Fazenda Demonstração).
- Imagens de satélite: Esri World Imagery (atribuição no mapa).
- Novidades da v0.6.10: o mapa abre onde foi deixado; Atividades (recentes por dia e tabela dos talhões); pinos agrupados com o mapa afastado.
