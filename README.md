# Monitoramento

App de campo (PWA de arquivo único) para monitorar pragas com GPS: mapa de severidade, visitas com tempo dentro da área, Semana e Anotações.
Abre sozinho no modo de demonstração, com dados inventados. Dentro do EFCwork, recebe o banco pelo `Monitoramento.iniciar({ fdb, usuario })`.

- Versão: 0.6.8 (23/11/2026): a área vista por dia (faixa do tempo, caminhamentos por pessoa e cartão do monitoramento), com a fazenda e as estruturas da v0.6.7
- Endereço: https://eliasgrigori.github.io/Monitoramento/
- Instalar no celular: abrir o endereço no Chrome › menu › "Adicionar à tela inicial" (iPhone: Safari › Compartilhar › "Adicionar à Tela de Início").

Créditos: Leaflet 1.9.4 (licença BSD-2), embutido no index.html.
